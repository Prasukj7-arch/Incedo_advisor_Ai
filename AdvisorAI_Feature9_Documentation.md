## 1. Feature Overview

Feature 9 implements the **Executive Dashboard** — the default home screen of Advisor AI. It serves as the unified command center that aggregates data from across the entire book of business and surfaces AI-generated proactive insights the moment the advisor logs in.

Instead of waiting for the advisor to ask a question, the dashboard proactively tells them what matters most before they click a single button. This transforms Advisor AI from a **reactive tool** into a **proactive concierge**.

This directly addresses **Section 12** of the problem statement:
> *"Advisor productivity improvement (% time saved), Reduction in client response time, Increase in AUM / revenue per advisor"*

**The demo moment:** Evaluator opens the app and immediately sees Total Book AUM ($3.4M), Compliance Health (0 Flags), Avg. YTD Return (13.7%), and 3 AI-generated proactive recommendations — one per client — all before clicking a single button.

## 2. Architecture

```
Browser loads app → loadDashboard() called automatically
        |
        v
GET /api/dashboard (FastAPI proxy — fast_app.py)
        |
        v
POST /dashboard (API Gateway → Lambda)
        |
        v
handle_dashboard_data() in lambda_handler.py
        |
        ├── Aggregates PORTFOLIO_DATA (total AUM, avg return, client count)
        ├── Builds book summary string for all 3 clients
        ├── Calls Bedrock (Llama 3.1 8B) for 3 proactive insights
        └── Returns structured JSON:
            {total_aum, avg_return, client_count, insights: [...]}
                |
                v
loadDashboard() in app.js renders:
- 4 KPI metric cards (top row)
- 3 AI Proactive Recommendation cards
- Static Audit Feed (right column)
```

## 4. Implementation Details

### 4.1 Lambda Handler — `handle_dashboard_data()`

```python
def handle_dashboard_data(body: dict) -> dict:
    # Aggregate book-level metrics
    total_aum = sum(c["aum"] for c in PORTFOLIO_DATA["clients"])
    avg_return = sum(c["ytd_return"] for c in PORTFOLIO_DATA["clients"]) / len(PORTFOLIO_DATA["clients"])
    
    # Build book summary for AI
    book_summary = "\n".join([
        f"- {c['name']}: ${c['aum']:,} | YTD: {c['ytd_return']}% | Risk: {c['risk_profile']}"
        for c in PORTFOLIO_DATA["clients"]
    ])
    
    # Generate insights via Bedrock
    prompt = f"""Analyze this book and provide 3 proactive insights (one per client).
    Return JSON array: [{{"type": "warning/info/success", "text": "...", "client": "Name"}}]
    JSON only."""
    
    answer_json, metrics = call_llama("You are a proactive advisor concierge.", [...])
    save_metrics("dashboard_insights", metrics)
    
    return {total_aum, avg_return, client_count, insights}
```

## 6. Graceful Fallback

If Bedrock returns malformed JSON, the dashboard falls back to 2 hardcoded insights so the page is never empty:

```python
except Exception as e:
    insights = [
        {"type": "info", "text": "Review today's top research reports for market shifts.", "client": "All"},
        {"type": "warning", "text": "Check equity concentration in aggressive portfolios.", "client": "Rahul Mehta"}
    ]
```
